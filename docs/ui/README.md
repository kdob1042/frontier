# Readerの画面検証

自作の架空記事を実Worker / D1へ保存し、本番用のViteビルドをChromiumで表示した証跡。
390px / 1280pxで検証。実在媒体の記事や本人の実記録は含まない。

| 画面   | 常時表示する主操作        | 証跡                                               |
| ------ | ------------------------- | -------------------------------------------------- |
| ホーム | 記事全体を開く1操作       | [スマホ](mobile-home.png) / [PC](desktop-home.png) |
| 本文   | なし。読むだけ            | [スマホ](mobile-reader.png)                        |
| 記録   | 検索欄1つ。入力すると検索 | [スマホ](mobile-archive.png)                       |

本文内の根拠リンクから原文の詳細を開いて段落へ移動する。
AI見方案の詳細内だけに「自分の見方にする」を置く。通常の本文には保存・翻訳・解析・分類ボタンがない。
管理・書き出しはowner用フッターから分離する。

確認済み：直接URL、再読込、既読位置の復元、根拠表示、本人の明示採用、採用後の検索、横はみ出しなし、読み直しでAIを呼ばない。
Safari実機、実媒体の取り込み・翻訳品質、公開先URLは未確認。

追加確認：ひと言メモ、本人文章の編集、関係の両側根拠と過去版リンク、AI改訂案の明示採用、管理の媒体設定。すべて自作の架空記事・fixtureで確認。

| 追加画面           | 主操作                | 証跡                             |
| ------------------ | --------------------- | -------------------------------- |
| 関係と見方の改訂案 | 展開した詳細の採用1つ | [スマホ](mobile-connections.png) |
| owner管理          | 媒体設定の保存1つ     | [スマホ](mobile-admin.png)       |

音声は開始前「聴く」だけを補助操作として表示。開始後は再生/一時停止と詳細、速度・音声・段落移動・終了は詳細内。非対応・端末内日本語音声がない場合は短い説明を表示する。制御fixtureによる操作確認で、実音声品質・Safari実機は未確認。

| ------------ | ------------------- | ------------------------------ |
