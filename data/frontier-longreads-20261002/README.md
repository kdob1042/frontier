# Frontier 長文記事カタログ

選定件数: **1000 / 1000**

本文1,500語以上・12段落以上の公式媒体記事を、署名・公開日・根拠への言及・テーマ・形式・重複で選別した台帳です。

- `index.html`: 単体で開ける検索・媒体/テーマ絞り込み付きカタログ。
- `catalog.json`: 最終選定した記事と原典URL・実測値。
- `report.json`: 件数、媒体、分野、公開年、除外理由、元データのコミット。
- `retrieval_audit.jsonl`: 取得と機械的審査のログ。
- `final_rejections.json`: 統合後の重複・形式による除外ログ。

全文転載・全文翻訳・本番の日本語記事への取り込みは含みません。記事ごとの自動検査は、全記事の精読・主張の独立検証とは異なります。本人の見方やAI知見を勝手に作成・採用していません。

収集基準日: 2026-10-02。記事の公開年を明記しており、古い記事を最新情報として扱いません。
